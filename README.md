# Lazlo · NFC 微信电子名片

原生 HTML / CSS / JavaScript 静态页面，无构建、外部依赖、广告或访客追踪。

## 修改

- `index.html`：名称、简介和使用说明。
- `styles.css`：配色及布局。
- `assets/wechat-qr.png`：展示和下载使用同一图片。换图时同步修改 HTML 的图片尺寸属性。
- `script.js`：图片加载失败提示。

二维码取自用户指定原图，只裁掉外围个人资料与原说明文字，保留二维码及约 50px 白边。790×790 PNG 与原图对应区域的解码 RGB 像素完全相同；未重绘、未缩放源图片。浏览器显示时按屏幕等比缩放。

## 本地预览

在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8765/`。

## GitHub Pages

发布来源设为 main 分支根目录（`/`），所有运行资源使用相对路径。`.nojekyll` 禁用 Jekyll 处理。首次公开上传须得到所有者明确确认。仓库、页面和二维码图片都会公开。

## 保存图片

标准浏览器通过同源 `download` 链接保存 PNG。部分手机浏览器或微信内置浏览器会改为预览图片；此时点开二维码并长按保存。页面不承诺可以绕过浏览器限制自动写入相册。

## NFC

在 NFC Tools PRO 写入记录中选择 URL / URI，填入已验证的 HTTPS Pages 地址，再写入标签。只需存储网址；网页和图片仍由 GitHub Pages 提供。二维码是否仍有效、微信能否成功加好友需在真实微信中确认。
